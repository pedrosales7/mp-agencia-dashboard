Análise de Cobertura e AssertividadeiUma linha por partner, Google e Meta lado a lado (cada canal tem sua própria base — Clickoff pro Google, Chat start pro Meta — então não faz sentido somar).

3 indicadores por canal:
  • % Cashback = cashback / bruto (investimento). Mede quanto do investimento voltou como cashback (leads/redirects pra outros provedores). Alto = muito reaproveitamento fora da cobertura do anunciante.
  • Leads totais = base de tráfego que chegou a interagir: Clickoff pro Google, Chat start pro Meta.
  • Leads com cobertura = quantos desses viraram lead produtivo no anunciante.
  • % Assertividade = Leads com cobertura / Leads totais.
Destaque visual: verde = melhor que mediana, vermelho = pior. Para %Cashback alto é tratado como "ruim" (pouca conversão pro anunciante); pra %Assertividade alto é "bom". Medianas calculadas separadamente por canal. Só entram partners com Bruto ≥ R$100 (cashback) ou Leads totais ≥ 20 (assertividade).
Leads aqui seguem a mesma atribuição por campanha/chat das tabelas de Funil completo em 7d/30d/90d/mês; em período customizado usa partner_id_partner direto — os dois métodos podem divergir levemente. Em período customizado, Leads totais e % Assertividade não ficam disponíveis (ver nota abaixo da tabela).

Pior que o padrão · Melhor · "—" = volume base insuficiente. % Cashback: alto = lead caiu fora da cobertura. % Assertividade: alto = tráfego virou lead próprio.

Evolução das taxas de conversãoiAparece quando você seleciona um partner específico, no seletor desta seção ou no filtro do topo (os dois ficam sincronizados).

Cada linha é uma etapa do funil, cada coluna é um período. A última coluna mostra a trajetória compacta (sparkline) e a variação em pontos percentuais vs. o período anterior.

Google:
  • Clique → Sessão
  • Sessão → Clickoff
  • Clickoff → Redirect
  • Redirect → Lead
  • Lead → Venda
Meta:
  • Clique → Chat start
  • Chat start → Zip search
  • Zip search → Redirect
  • Redirect → Lead
  • Lead → Venda
Fonte: mesmos eventos do "Funil completo" acima, agregados por semana/mês.

Quando o denominador é menor que 5, a célula mostra a contagem bruta (ex.: "1/2") em vez da taxa, para não induzir a erro com base pequena (1 venda sobre 2 leads não é uma taxa de 50% confiável) — mas sem esconder o dado. Quando o denominador é zero, mostra "—".

Cor do delta: verde = taxa subiu, vermelho = caiu. Ponto final da sparkline pinta na mesma lógica.
